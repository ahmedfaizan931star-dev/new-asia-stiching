New Asia Stitching Studio website

Upload every file in this folder to the ROOT of your repo/Vercel project (index.html and all .webp images together), then commit/redeploy.
To change a photo, replace the .webp file with the same name.
Prices: open index.html and search for "from Rs" to edit them.
The idea1-idea12 images are sample style visuals, labelled as such on the page.
